# Restaurant_Landing_Page Website

A self-practice project built to improve front-end development skills using HTML, CSS, and JavaScript. This project focuses on responsive layouts, clean UI structure, and basic interactivity.


📝 About

This project was created as a learning exercise to strengthen core web development concepts such as:

1. Responsive design principles.

2. Structured HTML and CSS organization.

3. Basic JavaScript for interactivity.

4. Designing user-friendly layouts.


🚀 Features

✔ Clean & Structured Layout – Simple and organized design.
✔ Responsive Design – Mobile-friendly and adaptive.
✔ Basic JavaScript Interactivity – Enhances user experience.
✔ Organized Sections – Menu items, feedback, and contact details.


🛠 Tech Stack

HTML5 – Structure

CSS3 – Styling and responsiveness

JavaScript – Dynamic interactivity
